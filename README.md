# IP Collaboration Atlas

Bilingual English / Chinese research pages for IP collaborations and touring exhibitions.

- Homepage: Collaboration Atlas
- Companion page: Exhibition Atlas

## GitHub Pages

Publish these files at the repository root. In Settings → Pages, select Deploy from a branch, the main branch, and / (root).

These are static HTML pages. Inquiry drafts are generated in the browser; the site does not send inquiries. Research and prioritization are assessments, not confirmed licensing availability.
